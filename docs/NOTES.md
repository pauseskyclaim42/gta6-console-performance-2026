# Developer Notes

## Scope

This tool is a read-only performance companion for the console version of GTA 6.
It helps the player adapt settings for a scene on a console and collects stutter logs.

## Recommendations

The companion provides recommendations. It does not raise performance numbers.
Preset values are based on public testing reports.

## Updating the source

Replace the preset data with the latest documented testing results and refresh the
platform comparison notes.

## Limitations

Game patches can change performance. Preset values and platform comparisons may
become outdated after updates.
